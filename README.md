# AskAI – Free AI Assistant

A fully free AI chat app powered by Google Gemini. No subscription. No credit card.

## Features
- 💬 Chat with Gemini 2.0 Flash, 1.5 Flash, or 1.5 Pro
- 📎 Upload images, PDFs, DOCX, CSV, TXT, JSON, ZIP, and more
- 🗂️ Conversation history (saved in your browser)
- 📤 Export chats as text files
- 🌙 Dark mode UI
- 📱 Mobile responsive

## How to use

### Option A – Open the HTML file directly
1. Download `index.html`
2. Double-click to open in your browser
3. Done!

### Option B – GitHub Pages (shareable link)
See deployment steps below.

## Get your free Gemini API Key
1. Go to [https://aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. Sign in with your Google account (no credit card needed)
3. Click **Create API key**
4. Copy and paste it into the app

## Deploy to GitHub Pages
1. Create a new repository on GitHub (e.g. `askai`)
2. Upload `index.html` to the repo
3. Go to **Settings → Pages**
4. Under **Source**, select `main` branch → `/ (root)`
5. Click **Save**
6. Your app will be live at `https://YOUR_USERNAME.github.io/askai/`

| File type | Support |
